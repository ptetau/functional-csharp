# FP0006: Legacy code must be called through an adapter

Using anything in a namespace listed in `functional_lint.legacy_namespaces` is reported, unless the code is inside an `[ImperativeAdapter]`.

## Why

Every place functional code touches imperative code should be explicit and easy to find. Adapters are those places.

## Instead

Before:

```csharp
public static class Report
{
    public static int Open(OrderService service) => service.GetOpenOrders().Count;
}
```

After:

```csharp
[ImperativeAdapter]
public sealed class Orders(OrderService service)
{
    public ImmutableArray<Order> Open() =>
        service.GetOpenOrders().Select(Order.From).ToImmutableArray();
}

public static class Report
{
    public static int Open(Orders orders) => orders.Open().Length;
}
```

## Auto-fix

None. Deciding the adapter's shape is a design choice.
