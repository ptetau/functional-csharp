# FP0001: Loops are not allowed

`for`, `foreach`, `while` and `do` are reported, and so are `goto` and `.ForEach(...)` calls (on `List<T>`, `ImmutableList<T>`, `Array` and `Parallel`), which are loops by another name.

Variables changed inside a loop (`i++`, `total += x`) aren't reported again under FP0002: rewriting the loop removes them.

## Why

A loop works by changing a variable on each pass. Describe the result instead, and the changing variable goes away.

## Instead

| You wanted to | Write |
|---|---|
| Transform each item | `Select` |
| Keep some items | `Where` |
| Add up, count, check | `Sum`, `Count`, `Any`, `All` |
| Build one value from many | `Aggregate` |
| Repeat n times | `Enumerable.Range(0, n).Select(...)` |
| Walk a tree | Recursion |

Before:

```csharp
decimal total = 0;
foreach (var line in order.Lines)
    total += line.Price * line.Quantity;
```

After:

```csharp
var total = order.Lines.Sum(line => line.Price * line.Quantity);
```

C# doesn't guarantee tail calls, so keep recursion for shallow structures such as trees.

## Auto-fix

None. Rewriting a loop needs to understand what it computes.
