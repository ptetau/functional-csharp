# FP0009: Adapters must not expose legacy types

A public, internal or protected member of an `[ImperativeAdapter]` whose signature uses a legacy type is reported. Constructors and private members are fine.

## Why

The adapter is the only bridge to legacy code. If it hands out legacy types, functional code ends up depending on them anyway.

## Instead

Before:

```csharp
[ImperativeAdapter]
public sealed class Orders(OrderService service)
{
    public LegacyOrder Get(int id) => service.Load(id);
}
```

After:

```csharp
[ImperativeAdapter]
public sealed class Orders(OrderService service)
{
    public Order Get(int id) => Order.From(service.Load(id));
}
```

## Auto-fix

None. You choose the functional type to map to.
