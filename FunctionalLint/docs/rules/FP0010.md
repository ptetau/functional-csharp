# FP0010: async void is not allowed

`async void` methods, local functions and lambdas are reported.

## Why

Nobody can await an `async void` method, so nobody can see when it finishes or whether it failed. Its exceptions crash the process.

## Instead

Before:

```csharp
public static async void Save(Order order) => await store.Write(order);
```

After:

```csharp
public static async Task Save(Order order) => await store.Write(order);
```

Event handlers that must be `async void` belong in an `[ImperativeAdapter]`.

## Auto-fix

Yes, for methods and local functions: the return type becomes `Task`, and `using System.Threading.Tasks;` is added if needed. Overrides, interface implementations and lambdas are left alone, because their signature is set elsewhere.
