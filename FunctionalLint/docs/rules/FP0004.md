# FP0004: Classes are not allowed

Plain classes are reported. Records, static classes, structs, interfaces, enums, delegates and attribute classes are fine.

## Why

A class bundles data with the methods that change it. Keeping data (records) apart from functions (static classes) makes both easier to test and reuse.

## Instead

Before:

```csharp
public class Order
{
    public int Id { get; set; }
}

public class Pricing
{
    public static decimal Total(Order order) => ...;
}
```

After:

```csharp
public record Order
{
    public int Id { get; init; }
}

public static class Pricing
{
    public static decimal Total(Order order) => ...;
}
```

## Auto-fix

Yes, when it's safe:
- A class with only static members becomes a `static class`.
- Any other class becomes a `record`, keeping its members, when that keeps its meaning (below).

It leaves a class alone if it has a primary constructor (a record would make the parameters public), inherits from another class, overrides `Equals(object)`, or is `partial`.

It also leaves a data class alone if code anywhere in the solution may compare or hash its instances. A class compares by reference and a record by value, so the change would make two equal objects that used to be different the same: `tags.Distinct().Count()` over two equal tags would go from 2 to 1. It counts:
- `a == b` and `a != b` (not against `null`), `Equals`, `GetHashCode` and assertions such as `Assert.Equal`;
- `Distinct`, `Contains`, `IndexOf`, `Except`, `Union`, `SequenceEqual` and friends over its instances;
- using it as the key of `GroupBy`, `ToDictionary`, `ToLookup`, `Join`..., or of a dictionary, set or equality comparer (`HashSet<Tag>`);
- a record, struct, tuple or anonymous type holding it, compared in any of these ways.

Grouping its instances by one of their members (`orders.GroupBy(o => o.Customer)`) doesn't count. When the fix leaves such a class, decide yourself: a record if value equality is what you want, or an `[ImperativeAdapter]` if it needs identity.

Code that needs a real class, such as an exception or a framework base class, belongs in an `[ImperativeAdapter]`.
