# FP0007: Throwing is not allowed

`throw` statements, `throw` expressions and rethrows are reported.

## Why

An exception is a hidden exit from a function: nothing in the signature says it can happen. Returning a result puts failure in the signature, so callers must handle it.

## Instead

Before:

```csharp
public static Order Find(ImmutableArray<Order> orders, int id) =>
    orders.FirstOrDefault(o => o.Id == id) ?? throw new KeyNotFoundException();
```

After:

```csharp
public static Result<Order> Find(ImmutableArray<Order> orders, int id) =>
    orders.FirstOrDefault(o => o.Id == id) is { } order
        ? new Ok<Order>(order)
        : new NotFound(id);
```

Catch exceptions from libraries in an `[ImperativeAdapter]` and turn them into results there.
