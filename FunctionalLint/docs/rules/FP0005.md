# FP0005: Mutable collection types are not allowed

Creating `List<T>`, `Dictionary<,>`, `HashSet<T>`, `Queue<T>`, `Stack<T>`, `LinkedList<T>`, sorted and concurrent collections, or `StringBuilder` is reported. So are `ToList()`, `ToDictionary()` and `ToHashSet()`.

## Why

A mutable collection can change after you've handed it on. Immutable collections can't, so they're safe to share.

## Instead

Before:

```csharp
var ids = orders.Select(o => o.Id).ToList();
var lookup = new Dictionary<int, Order>();
```

After:

```csharp
var ids = orders.Select(o => o.Id).ToImmutableArray();
var lookup = orders.ToImmutableDictionary(o => o.Id);
ImmutableArray<int> small = [1, 2, 3];
```

Watch out: methods like `Add` on an immutable collection return a new collection. Use the result, or nothing happens.

## Auto-fix

None. Swapping in an immutable type would silently break code that calls `Add` and ignores the result.
