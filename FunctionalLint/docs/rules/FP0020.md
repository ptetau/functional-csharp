# FP0020: Only the functional subset of .NET

A core may use the parts of .NET's own library listed in [`ApiSubset.cs`](../../src/FunctionalLint/ApiSubset.cs). Anything else is reported where it's used.

Allowed:
- **Whole namespaces:** `System.Linq`, `System.Collections.Immutable`, `System.Collections.Frozen`, `System.Collections.Generic`, `System.Text`, `System.Text.RegularExpressions`, `System.Text.Json` (and `.Serialization`, `System.Text.Encodings.Web`), `System.Numerics`, `System.Globalization`, `System.Diagnostics.CodeAnalysis`.
- **Single types from `System`:** the primitive types, `string`, `Math`, dates and times, `Guid`, `Uri`, `Version`, `Enum`, `Array`, `Convert`, `Nullable`, `Index` and `Range`, `ReadOnlySpan<T>`, `Lazy<T>`, `Func` and `Action`, tuples, comparison interfaces and attributes.
- **Any attribute,** anywhere: attributes are declarations, not behaviour.

Never allowed, even on an allowed type:
- `GetHashCode`, `HashCode`: string hashes change between runs.
- `GetType`: it's the way into reflection.
- Enumerators stepped by hand (`IEnumerator<T>`): they're mutable state.

Not reported here because other rules report them with better advice: side effects such as the clock, the console and files (FP0011), and mutable collections (FP0005, FP0008). FP0018 decides which libraries other than .NET a core may use.

A library's contract is allowed where you implement it: an override or interface implementation may call the member it implements (`GetEnumerator` forwarding to an inner list), and a `GetHashCode` override may hash. Adapters are exempt.

The project owner can allow more in the policy: `functional_lint.allowed_apis = System.Threading.Tasks.Task.FromResult, System.Buffers`. An entry is a namespace, a type or a member.

## Why

.NET's library is huge, and most of it was written for imperative code: threads, locks, the garbage collector, interop, reflection. A list of what to forbid would never be finished. A list of what to allow is short, and can be reviewed.

## Instead

Before:

```csharp
public static string Summary(ImmutableArray<Line> lines) =>
    string.Join(",", lines.Select(l => l.Sku.GetHashCode()));
```

After:

```csharp
public static string Summary(ImmutableArray<Line> lines) =>
    string.Join(",", lines.Select(l => l.Sku));
```
