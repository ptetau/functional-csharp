# FP0011: Side-effecting API

Reading the clock, `Guid.NewGuid`, `Random`, the console, files, `HttpClient`, processes, `Stopwatch`, `Thread.Sleep` and `Task.Delay` are reported as having side effects.

The environment, `CultureInfo.CurrentCulture`, `TimeZoneInfo.Local`, `Path.GetFullPath` and `Path.GetTempPath` are reported as depending on the machine. Parallel LINQ (`AsParallel`) and `Parallel` are reported because they run work in an unpredictable order: summing doubles in parallel can give different bytes on each run.

Add more with `functional_lint.impure_apis`.

## Why

A function that reads the clock or the disk can give a different answer for the same input. That makes it hard to test and hard to reason about.

## Instead

Pass the value in, or wrap the API in an adapter.

Before:

```csharp
public static bool IsOverdue(Invoice invoice) => invoice.Due < DateTime.UtcNow;
```

After:

```csharp
public static bool IsOverdue(Invoice invoice, DateTime now) => invoice.Due < now;
```

## Auto-fix

None. Where the value should come from is a design choice.
